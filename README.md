# WarmSlider

WarmSlider is a small Linux utility for adjusting display color temperature
and brightness. It supports X11 through `xrandr` and uses GNOME's native
night-light service as a fallback on Wayland.

## Features

- Live color-temperature control from 2500 K to 6500 K
- Live brightness control from 20% to 100% where supported
- Automatic detection of connected X11 displays
- GNOME/Wayland night-light integration
- Persistent settings and one-click neutral reset

## Privacy

WarmSlider does not collect or transmit user data. The optional Donate button
only opens the configured donation page in the user's browser.
